Dynamic Routing Using RIP v2 in Cisco Packet Tracer

This project demonstrates the implementation of Dynamic Routing using RIP Version 2 (RIPv2) in Cisco Packet Tracer. The network consists of three interconnected Cisco routers, three LAN segments, switches, PCs, and servers. RIPv2 is configured to enable automatic route discovery and route sharing between routers, eliminating the need for manual static routing.

Project Objectives
Design a multi-router network topology.
Configure IP addressing for routers and end devices.
Implement RIP Version 2 dynamic routing.
Verify automatic route propagation between routers.
Test end-to-end connectivity across multiple LANs.
Technologies Used
Cisco Packet Tracer
Cisco 1941 Routers
Cisco 2960 Switches
RIP Version 2 (RIPv2)
FastEthernet and Serial WAN Links

Verification
